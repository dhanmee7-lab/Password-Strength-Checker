Password Strength Checker



A Python cybersecurity project that evaluates password strength

using entropy calculations and security policy criteria.



Features

\- Password length validation

\- Uppercase and lowercase checks

\- Number and special character checks

\- Password entropy calculation

\- Common password detection

\- Strength classification

\- Actionable security feedback



Requirements

\- Python 3



How to Run



```bash

python password\_checker.py
